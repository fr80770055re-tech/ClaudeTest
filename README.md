# ClaudeTest

國小數學與教室用的小工具，用 GitHub Pages 發布。

- `index.html`：周長與面積出題工具（四年級）
- `distributive/`：分配律與交換律圖解（五年級）。分配律用長方形面積模型拆開乘法（205 × 15 = 200 × 15 + 5 × 15），可拖曳切線、一步一步顯示算式，也有「找找看錯在哪」；交換律把長方形轉 90° 看出 a × b = b × a，也能用在連乘簡算（25 × 37 × 4 = 25 × 4 × 37）。各分頁有內建例題、隨機出題，也能存自己的例題（存在這台裝置的瀏覽器裡）。
- `clock/`：橘子時鐘（園遊會攤位用 iPad 時鐘）
